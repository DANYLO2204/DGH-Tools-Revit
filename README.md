# DGH Tools for Revit

DGH Tools is a lightweight Revit 2023 add-in currently focused on fast datum/grid editing workflows.

## Current tool

- **Align Grid Ends** — align one end of multiple parallel straight grids in the active view using 2D/View Specific extents.

## Auto-update

Installed builds check `update/update.json` from this repository in the background. A newer validated source is downloaded, compiled against the local Revit 2023 API after Revit closes, and becomes active on the next launch.

Current version: **0.6.0**
